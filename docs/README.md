# Documentation

_Last reviewed: 2026-08-27_

This tree explains EasyKey for human readers: what the menu-bar Vietnamese app does, how it is built, how it runs, and how to operate and review it. Engineers and beginners share these pages; there is no separate coding-agent view in this run.

## At a glance

Product and flows say what happens. Architecture says how the pieces fit. Engineering and contributing say how to change it. Operations and security say how it ships and what it trusts. Reference holds lookup tables. Concepts and decisions stay empty until harvest finds records.
